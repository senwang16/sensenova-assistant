⚙️ 设置

每个供应商独立保存 Base URL、API Key 池与模型列表；切换即生效，聊天自动跟随所属供应商。
高级：接口端点（OpenAI 兼容）
关闭后所有文本模型使用非流式请求（最稳定，等同 curl 行为）；个别流式异常的模型会被自动标记并单独走非流式
自动 Round-Robin 轮换；遇 429 限流 / 401 鉴权失败自动切换下一个 Key 静默重试
🧠 记忆系统（三层记忆）
更早的对话自动压缩为要点综述，主线不丢失
综述与查询改写共用此链：前一个模型失败/限流时自动切换下一个
向量库为浏览器本地 IndexedDB；嵌入优先探测网关 /embeddings，不支持时自动使用本地词法嵌入（零下载）
仅在问题含指代词时触发；每次多一次小模型调用，换取更准的召回
🗄 存储管理
彻底删除/清空聊天会自动清理其向量与综述；恢复聊天自动重建向量；存储占用为浏览器分配给本插件的总空间
