# SenseNova Assistant 🚀

> 商汤大模型（SenseNova）多账号智能助手 —— 一款纯原生、零依赖的 Chrome 扩展

一款功能完整的**商汤 / Agnes** 多模态浏览器助手：多 API Key 智能轮换、429/401/5xx 无感重试、免费额度限流排队、文本 / 绘图 / 视频三类模型智能路由与**按意图自动分流**、媒体本地永存、三层记忆系统、会话管理与回收站，全部数据本地存储，不上传任何服务器。

## ✨ 核心特性

### 🔑 多账号 Key 管理
- **Round-Robin 轮换**：多个 API Key 自动轮流使用，均摊配额
- **429 限流处理**：被限流的 Key 自动冷却，指数退避后静默重试，切换到下一个可用 Key
- **401 失效检测**：失效 Key 自动标记，不干扰正常请求
- **实时状态面板**：每个 Key 的可用性、冷却状态一目了然

### 🌐 多供应商（多端）支持
- **一站式接入多家大模型**：可同时配置商汤、Google Gemini、Kimi、DeepSeek、OpenAI 等任意 OpenAI 兼容网关
- **预设模板**：新增强时一键填充已知供应商的 Base URL 与端点，避免手填
- **按供应商隔离**：每个供应商独立保存 Base URL、API Key 池、模型列表、尺寸设置与选项，互不干扰
- **快速切换**：顶栏设置面板下拉即可切换当前供应商，切换即生效
- **会话自动跟随**：每个聊天自动记住所属供应商，切换聊天时自动切回对应端，模型列表随之变化
- **绘图能力自动识别**：无绘图接口的供应商（如 Google/Kimi）会明确提示，而非报错
- **无缝迁移**：旧版单端配置自动升级为第一个供应商，历史数据不丢失

### 🤖 智能模型路由
- **自动发现**：通过 `/models` 接口拉取全部可用模型
- **关键词分类**：按关键词自动区分文本模型（SenseChat / DeepSeek / GLM 等）、绘图模型（U1 系列、agnes-image 等）与视频模型（agnes-video 系列）
- **手动修正**：分类错误可一键切换模型类型
- **多模型切换**：会话内随时切换模型，设置按会话独立记忆

### ⚡ 多模态自动路由（按意图分流）
- **一个「自动」选项**：模型列表选 **⚡ 自动（按意图路由）**，不用再手动切模型
- **说人话即可**：说「画一只猫」自动走图片模型、「生成一段视频」自动走视频模型，其余走文本模型
- **三级判定**：显式指令（`/img` `/video` `/chat`）→ 强模式正则（只认祈使句）→ 兜底文本
- **宁可聊天不误生成**：「怎么画图」「生成一段调用视频接口的代码」这类提问不会被误判
- **能力槽位**：在设置里为 文本 / 图片 / 视频 各指定一个模型；自动模式会跨供应商找有该能力的一家执行，全都没有时才降级为文本并提示
- **跨供应商**：文本与图片 Agnes、商汤均可用，失败可互相兜底；视频目前仅 Agnes 提供 —— 自动模式下即使当前在商汤，也会自动改用 Agnes 执行（视频候选只含已开启视频能力的供应商，不参与互为备胎）
- **模型白名单**：可限定只显示白名单内的模型（Agnes 预设默认只留免费模型），避免误选收费模型

### 🚦 限流排队与重试
- **免费额度感知**：仅对 Agnes 生效，按官方「实际可执行 RPM」排队（文本 10（2026-09-23 官方下调）/ 图片 1K-2K 为 20-10 / 3K-4K 为 1 / 视频 1）
- **Key 共池不放大**：官方确认同类型 Key 共享同一限制池，多把免费 Key 不增加 RPM
- **5xx 指数退避**：500/502/503/520 自动退避 `2s → 6s → 15s` 重试，最多 3 次
- **状态码分流**：400/404 直接抛错便于定位，401 冷却 Key 并切换，429 冷却后轮换
- **供应商健康标记**：某家失败后短时间冷却（429/配额类 90s，服务端/网络类 30s），自动路由优先绕开它；成功即恢复

### 💬 对话体验
- **流式输出（SSE）**：打字机效果实时显示
- **多轮上下文**：自动携带最近对话历史
- **会话管理**：左侧常驻会话栏，新建/重命名/删除/切换
- **会话分组**：按日期/分类自动收纳，可折叠
- **回收站**：删除的会话可恢复，彻底清理时同步删除文字、图片与向量数据
- **全屏模式**：一键放大为完整页面
- **停止按钮**：随时中断生成
- **可拉伸输入框**：手动拖拽调整高度并记忆

### 🎨 绘图模型支持
- **两套参数自适应**：商汤用精确像素白名单（内置 U1 全部 13 种合法尺寸，杜绝 `400 Size invalid`）；Agnes 用「档位 1K/2K/3K/4K + 画幅比例」，按当前供应商自动切换控件
- **旧尺寸自动迁移**：历史设置自动迁移到最近似合法尺寸
- **图片本地永存**：生成的图片 URL 仅 1 小时有效，扩展自动抓取转 Base64 存入本地，**永不过期**
- **图片限额管理**：最多 20 张 / 10MB，自动淘汰最旧的图片防止撑爆存储

### 🎬 视频生成（Agnes）
- **异步任务全流程**：创建任务 → 轮询结果 → 下载转 Base64 本地缓存，全程进度可见、可随时停止
- **参数合规**：按 2.5 系列规范发送 `mode` / `seconds`（4–12 秒）/ `size("720P")` / `aspect_ratio`
- **轮询鉴权一致**：锁定「创建任务时那把 Key」复用，避免多 Key 轮换导致查不到任务
- **域名自适应**：轮询地址由 Base URL 推导，国际站 `apihub.agnes-ai.com` 与国内站 `api.agnes-ai.cn` 均可
- **1 RPM 冷却**：免费额度每分钟仅 1 个任务，发送前倒计时提示，避免连点触发 429
- **视频限额管理**：最多 10 段 / 300MB，超出自动删最旧
- **开关可控**：设置面板「视频生成能力」默认关闭，未开启时 🎬 模型不可选

### 🧠 三层记忆系统
| 层级 | 名称 | 说明 |
|------|------|------|
| L1 | 近期原文 | 最近 5-10 轮对话原样保留（默认 8 轮，可配置） |
| L2 | 滚动综述 | 更早的对话后台自动压缩为要点综述，主线不丢失 |
| L3 | 向量检索 | 全部会话问答对入本地向量库，对话时召回 Top-K 相关历史注入上下文 |

- **本地向量库**：基于 IndexedDB，零下载零依赖，数据完全本地化
- **嵌入策略**：优先探测网关 `/embeddings` 接口，不支持时自动回落本地词法嵌入
- **查询改写**：检索前可让大模型改写提问、消解指代（可开关，超时自动用原句）
- **综述模型链**：可配置多个模型按优先级依次尝试，支持自定义总结模型
- **严格超时保护**：记忆检索总预算 8s，超时自动放弃本层，**绝不阻塞消息发送**
- **会话隔离**：检索召回跨会话相关历史，但各会话上下文互相独立

### 🗄 存储管理（可视化）
- **占用统计**：storage / IndexedDB 使用量实时可视化
- **分类明细**：会话数据、图片缓存、向量库分别统计
- **一键清理**：支持按类别清理，彻底删除不留残余

### 🎨 界面
- 浅色 / 深色双主题
- Markdown 渲染 + 代码高亮 + 一键复制
- 现代简洁风格，响应式布局

## 🔒 隐私说明

- **所有数据（Key、对话、图片、向量）仅存储在本地浏览器**（chrome.storage + IndexedDB）
- 不内置任何统计、埋点或第三方服务
- Key 仅在请求商汤 API 时使用，不经过任何中间服务器

## 📦 安装（开发者模式）

1. 下载本项目代码（`git clone` 或下载 ZIP 解压）
2. 打开 Chrome，访问 `chrome://extensions/`
3. 开启右上角 **开发者模式**
4. 点击 **加载已解压的扩展程序**，选择项目根目录（含 `manifest.json` 的文件夹）
5. 点击浏览器工具栏中的扩展图标即可使用

## ⚙️ 配置指南

### 第一步：添加 API Key
1. 打开扩展，进入 **设置**
2. 在 **服务供应商** 下拉中选择你要用的供应商（商汤 / Google / Kimi / DeepSeek / OpenAI，或新建自定义）
3. 选择供应商后，在 **API Key 池** 中粘贴该供应商的 API Key（支持添加多个，自动轮换）
4. 点击 **获取模型列表**，扩展会自动拉取并分类该供应商下所有可用模型

### 第二步：选择模型
- **文本对话**：从模型选择器中选择当前供应商下的文本模型（如 SenseChat、Gemini、agnes-3.0-flash 等）
- **图片生成**：选择绘图模型（如商汤 U1、agnes-image-2.5-flash），发送提示词即可生成图片
- **视频生成**：先在 **设置 → 高级 → 视频生成能力** 打开开关，再选 🎬 视频模型（如 agnes-video-2.5-flash）
- **⚡ 自动（推荐）**：选顶部「自动（按意图路由）」，之后按输入内容自动决定走文本 / 图片 / 视频，无需手动切换

### 多供应商使用提示
- **新增供应商**：设置面板顶部选预设（或选"自定义"），填好名称与 Key 后即可
- **切换供应商**：顶栏设置面板下拉直接切换，模型列表与 Key 状态随之更新
- **会话关联**：每个聊天记住所属供应商，切换聊天自动切回对应端，无需手动换
- **能力差异**：文本与图片 Agnes、商汤都可胜任；视频目前仅 Agnes 提供 —— 手动模式下该供应商须先开启「视频生成能力」，否则 🎬 模型显示为灰色不可选；自动模式下当前在商汤也会自动改用 Agnes 执行
- **模型白名单**：设置 → 自动路由与模型白名单，可限制只显示白名单内的模型；Agnes 预设默认只保留免费模型，避免误选收费模型

### 常用预设网关
```
商汤    https://token.sensenova.cn/v1
Agnes   https://apihub.agnes-ai.com/v1          （国际站）
        https://apihub.agnes-ai.cn/v1           （国内站，账号与 Key 与国际站不通用）
Google  https://generativelanguage.googleapis.com/v1beta/openai   （OpenAI 兼容）
Kimi    https://api.moonshot.cn/v1
DeepSeek https://api.deepseek.com/v1
OpenAI  https://api.openai.com/v1
```
均兼容 OpenAI 接口规范（`/chat/completions`、`/images/generations`、`/models`），也支持手动填写任意自定义兼容网关。

### 文本 / 图片 / 视频 的供应商支持
| 能力 | 商汤 SenseNova | Agnes | 说明 |
|---|---|---|---|
| 文本 | ✅ | ✅ | 任意 OpenAI 兼容网关均可 |
| 图片 | ✅（精确像素尺寸） | ✅（档位 + 比例） | 参数形态不同，扩展自动切换控件 |
| 视频 | ❌ | ✅ `agnes-video-2.5-flash` | 异步任务，免费额度 1 次/分钟 |

> 切换供应商即切换能力来源：顶栏 ⚙️ → 服务供应商列表点击即可；聊天会自动跟随所属供应商。

## 🛠 技术栈

- **Chrome Extension Manifest V3**
- **原生 JavaScript**：无任何框架与依赖，加载快、体积小
- **IndexedDB**：本地向量库存储
- **SSE (Server-Sent Events)**：流式对话输出
- **Base64 图片缓存**：解决商汤图片 URL 1 小时过期的限制

## 📝 使用提示

- **绘图尺寸**：如遇 `400 Size invalid`，请从设置中的尺寸下拉框选择（已内置全部合法值）
- **Key 冷却**：提示"所有 Key 均被限流"时扩展会自动重试，无需手动干预；若长期如此请检查 Key 配额
- **图片保存**：生成的图片已本地缓存，也可右键另存为导出
- **记忆检索**：首次使用向量检索会自动探测嵌入接口，失败时回落本地词法嵌入（语义匹配精度略低但仍可用）
