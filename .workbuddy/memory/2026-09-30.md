### 官方限流（免费/default Key，实际可执行 RPM）
- 文本 20 RPM；图片 1K=20 / 2K=10 / **3K=1 / 4K=1**；视频 **1 RPM**
- 免费 Key 无每日配额（500 秒/天 是订阅才有）
- 3K/4K 图片 1 RPM 即使付费也不提升 → 默认档位保持 2K

### 新发现：视频参数存在代际差异（原代码只写了一套）
- `agnes-video-v2.0`：`num_frames`(8n+1) + `frame_rate` + `width`/`height`
- `agnes-video-2.5-flash`：`seconds`("4"–"12") + `size`("720P") + `aspect_ratio` + `mode`(必填)
- 查询：v2.0 用 `?video_id=`；2.5 用 `?video_id=&model_name=`
→ 需 `buildVideoBody(model)` 分支

### 设计要点
- 新增 `RateLimiter`：按「Key × 能力 × 档位」滑动窗口记账；发送前 acquire，不足则显示排队倒计时
- 重试分流：400/404 不重试；401 冷却 Key 换 Key；429 读 `Retry-After` 退避≤2轮；5xx 指数退避 2s→6s→15s ≤3次
- 视频轮询固定复用建任务的 Key、不走轮换、不计入视频 RPM
- 视频限频是账号级，多 Key 无法突破
- 供应商加 `allowedModels` 字段，`renderModelDropdown` 按白名单过滤
